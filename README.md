# PCLUnlock

## 简介

通过代理 **PCL2** 的 **d3d9.dll** 实现解锁，用于恢复下载相关的受限功能。

## 构建依赖

- Visual Studio 2022：C++ 桌面开发、.NET 桌面开发工作负载
